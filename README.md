# 🔤 Morse Code Converter

A simple and interactive **Morse Code Converter** built using HTML, CSS, and JavaScript. This project allows users to convert text into Morse code and decode Morse code back into readable text instantly.

## 🚀 Features

- Convert text → Morse code
- Convert Morse code → text
- Real-time conversion
- Clean and responsive UI
- Beginner-friendly project

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
